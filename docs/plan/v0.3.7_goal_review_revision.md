## 三、loop 自评（本会话元反思）

**做得好的**：
1. 不满足"症状消失"——第 1 轮声称修好后仍不探索，继续深挖到 4 层根因
2. 每个修复都有**端到端实测证据**，不是"应该生效"
3. 每层加回归护栏，锁死不复发
4. 主动纠错：上一轮把整表 task_type 分布误当 pending 分布，明确修正

**教训沉淀**：
1. "修完一个 bug 就以为好了"是最大陷阱
2. 静默失败有线程级/语义级/数值级三层
3. 符号级去重脆弱：单字/超通用词必然跨域误合并
4. 数据聚合先确认 WHERE 再解读

**loop 有效性**：本会话 3 轮 loop，从"计划基本未执行" → 
"16 commits + 双线闭环 + 52 回归测试"，且每轮都比上一轮更接近根因。
